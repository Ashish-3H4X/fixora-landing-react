# Fixora Landing Page

React + Vite + Tailwind CSS landing page for the Fixora local-services marketplace.

## Run

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

The page is responsive and includes:
- Responsive navbar
- Hero section with app mockups
- Why Fixora section
- Popular services
- How it works
- Professional/business section
- Customer testimonials
- App download CTA
- Footer
